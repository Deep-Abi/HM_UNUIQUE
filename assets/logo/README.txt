-----------------------
Supplied originals (do not edit or overwrite):
- icon/transparent, icon/white       (infinity "HM" icon; AVIF/PNG/WebP, white-backed AVIF/JPG/WebP)
- logo/transparent, logo/white       (full logo with "HM UNIQUE" wordmark)

Site derivatives (web/): tightly cropped from the transparent originals, scaled only
(no redesign or recolouring). Icon heights 48/96/144, full logo heights 64/128/192,
each as AVIF + WebP + PNG.

The header, drawer and footer use the icon (web/hm-unique-icon-*) beside live HM UNIQUE
text, because the full logo's wordmark is too small to read at header height. The full
logo (web/hm-unique-logo-192.png) is the structured-data logo.
The footer places the icon on a white backing because the navy artwork vanishes on navy.

Legacy placeholder SVGs (hm-unique-logo.svg, hm-unique-logo-light.svg) are no longer
referenced by any page; kept only until the owner confirms they can be deleted.
