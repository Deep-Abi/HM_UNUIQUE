# HM UNIQUE — keyword-to-page map (Batch 31)

**How to read this.** Three kinds of statement are kept apart:
- **Researched evidence** — something actually seen in a source on 2026-11-23 (listed in section 1).
- **Proposed theme** — a reasoned search topic. It is *not* a measured query.
- **Not available** — search volumes, competition scores and rankings. No keyword tool or Search Console data was available, so **none are given or implied**.

No meta-keywords tag is used anywhere, and each keyword theme is placed only on the page it belongs to.
